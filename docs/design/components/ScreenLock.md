# ScreenLock

Экран входа: монограмма-файл, «С возвращением», точки PIN и моно-клавиатура с отпечатком и стиранием.

**Правила**
- Биометрия запускается сама при открытии; PIN — запасной путь.
- Клавиши 76 px, цифры моно, фон клавиш `surface`; биометрия и стереть — без фона.
- Фейк-калькулятор после тройного нажатия не наследует ни одного токена МС: системные цвета, системный шрифт, своя иконка.
