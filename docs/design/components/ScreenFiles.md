# ScreenFiles

Экран «Файлы»: общая папка пары на Яндекс.Диске — теги, список файлов с автором, сроки документов и личный сейф.

**Правила**
- Под заголовком всегда строка хранилища: где лежит, сколько занято, когда был синк.
- Фильтр — `Chips` с количеством; поиск — по имени и тегам (не по содержимому, I6).
- Срок документа — бейдж `warn` с текстом `on-warn` за 60 дней до окончания.
- Личный сейф — последней строкой, превью без содержимого (`flame-soft` + замок).
- Две кнопки добавления над таб-баром: «Скан» (вторичная) и «Файл» (основная).
