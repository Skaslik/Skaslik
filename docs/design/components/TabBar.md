# TabBar

Нижняя навигация из пяти вкладок: Дом, Календарь, Файлы, Вместе, Мы.

**Что передаёт приложение:** активная вкладка и бейджи (точка `sofia`/`michael` — новое от партнёра).

**Правила**
- Иконки Material Symbols Rounded 24: `cottage`, `calendar_month`, `folder_open`, `join_inner`, `favorite`; у активной — заливка (FILL 1) в пилюле `flame` 56×30.
- Подписи всегда видны (`tab-label`), активная — полужирная.
- Высота `tabbar-h` + системный отступ; фон `surface`, сверху линия `line`.
