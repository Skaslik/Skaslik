# EventRow

Строка события: блок даты (моно), полоса автора, название и мета, справа — подсказка-иконка (место, напоминание, повтор).

**Что передаёт приложение:** дата/интервал, автор (`michael | sofia | both`), заголовок, время, последняя правка, тип иконки.

**Правила**
- Полоса 3 px цвета автора; общее — две половинки.
- Мета: «19:30 · добавила София»; для многодневного — «3 дня · поездка».
- Тап — карточка события; долгий тап — быстрые действия (напомнить, маршрут).
