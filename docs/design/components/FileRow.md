# FileRow

Строка файла: превью-тип, имя, мета с автором, бейдж срока и меню.

**Правила**
- Превью 44×52, радиус `radius-sm`; для PDF/JPG подпись типа моно 8 px.
- Мета: точка автора · размер · тег · когда; бейдж срока переносится на вторую строку.
- Личный сейф — тот же ряд, но подложка `flame-soft` и замок, без числа файлов.
