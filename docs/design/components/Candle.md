# Candle

Общая свеча: зажгли на одном телефоне — горит на обоих; это главный ритуал «я рядом».

**Состояния:** `off` (фитиль, тонкий дымок) · `pending` (горит у вас, партнёру ещё не доставлено — строка статуса с `◐`) · `lit` (горит у обоих, в строке — кто зажёг и когда).

**Что передаёт приложение:** состояние из CRDT-домена `ritual` (kind = beacon), имя и пол того, кто зажёг (для «зажёг/зажгла»), время.

**Правила**
- Пламя — `candle-flame` + `flame-core`, ореол — `flame-glow`. Свечение не используется больше нигде в интерфейсе.
- Строка статуса под сценой — `flame-soft` с текстом `ink`; погасшая — `surface`.
- Тап по горящей свече ничего не гасит случайно: гасит долгое нажатие или полночь (см. «Что согласовать»).
- Партнёр получает тихое уведомление «София зажгла свечу» с одной короткой вибрацией (PLAN 7).
