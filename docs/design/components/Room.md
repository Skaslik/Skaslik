# Room

Главная сцена «Дома»: уютная комната с окном, свечой на подоконнике, запиской на стене и черно-белым басенджи на кресле — каждый предмет что-то значит.

**Что передаёт приложение (Flutter-виджет `RoomScene`):**
- `weather` — `{kind: clear|cloudy|rain|snow, isNight, tempC, label, place}`; источник — см. раздел «Комната».
- `candle` — `off | lit | pending` из домена Ritual (beacon) — состояние общее для пары.
- `note` — последняя записка партнёра `{text, by, sign}` или `null`.
- `onCandleTap`, `onWindowTap`, `onDogTap`, `onNoteTap`, `onFrameTripleTap` (фейк-режим).

**Правила**
- Сцена рисуется векторно (CustomPainter или Rive), все цвета — токены `scene-*`, `dog-*`, `candle-*`, `sky-*`; тема «Вечер»/«День» перекрашивает комнату целиком.
- Небо в окне следует за реальным временем суток и погодой, а не за темой.
- Каждая зона нажатия ≥ `tap-min` (48 px), у каждой — семантическая подпись для TalkBack/VoiceOver.
- Анимации только живые и тихие: пламя мерцает, собака дышит. При «уменьшить движение» всё замирает.
- Не добавлять предметы «для красоты» — каждый новый предмет должен нести смысл (инвариант I9).
