# PiggyBank

Карточка копилки: категория, название, полоса вкладов по людям, сумма и арифметический прогноз.

**Правила**
- Полоса делится на сегменты `michael`, `sofia` и `warn` (штрафы) — пропорционально вкладам.
- Под полосой — сумма `number-md` и «из N ₽», ниже — вклады людей и прогноз моно.
- Бейдж «+5 000 сегодня» — `flame-soft`, только в день взноса.
