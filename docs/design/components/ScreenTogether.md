# ScreenTogether

Экран «Вместе»: общий быт пары за переключателем «Копилки · Списки · Карты»; на картинке — копилки.

**Правила**
- Карточка копилки: надбровье-категория, название `title-sm`, полоса вкладов по людям, сумма `number-md`, моно-прогноз.
- Штрафы — сегмент `warn` в полосе и строка с иконкой молотка; формулировки с юмором, но без эмодзи.
- Завершённые копилки уходят в «Архив · N» внизу списка, а не исчезают.
