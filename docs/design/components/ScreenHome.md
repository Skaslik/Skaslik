# ScreenHome

Экран «Дом»: сверху на ~ половину экрана комната, снизу лист «Сегодня» с приветствием, статусом свечи, ближайшими событиями и картами под рукой.

**Состав листа (сверху вниз):** приветствие `room-greeting` + статус синка → строка свечи → «Сегодня · <дата>» и до трёх `EventRow` → «Карты под рукой» (топ‑3 карты) → ниже по скроллу: копилка-лидер, новый файл.

**Правила**
- Лист тянется вверх и закрывает комнату только по жесту; по умолчанию комната видна целиком до кресла.
- Обращение по имени в той форме, что выбрали в онбординге («Миша», «Соня»).
- Приветствие по времени: «Доброе утро / Добрый день / Добрый вечер / Доброй ночи».
- Пустые состояния тёплые и короткие, без эмодзи: «Сегодня ничего не запланировано — можно просто побыть вместе».
