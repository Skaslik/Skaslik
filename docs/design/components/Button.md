# Button

Кнопки: основная (одна на экран), вторичная, текстовая и удаление.

**Правила**
- Основная — `flame` с текстом `on-flame`, высота 48, радиус `radius-md`; глагол первым: «Добавить событие», «Зажечь свечу».
- Вторичная — `surface-raised` с обводкой `line`; текстовая — цвет `link`.
- Удаление — `danger` + `on-danger` и всегда с подтверждением; «Стереть всё» требует обоих (двухфакторное удаление).
- Маленькие (36, пилюля) — для действий в строке: «Беру», «+ Файл».
