# SyncStatus

Статус синхронизации: знак и слово, никогда только цвет.

**Состояния:** `●` синхр. (`success`) · `◐` ждут синка · N (`warn`) · `○` офлайн (`ink-muted`) · `✕` ошибка с причиной (`danger`).

**Правила**
- Живёт в шапке листа «Дома» и в «Мы → Синхронизация»; тап — «Синхронизировать сейчас».
- Формулировка честная, без паники: «почти мгновенно рядом, минутно на расстоянии» (PLAN 2.3).
