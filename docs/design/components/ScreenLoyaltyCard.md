# ScreenLoyaltyCard

Полноэкранная карта лояльности для кассы: белый лист, крупный штрихкод EAN-13/QR, яркость 100%, экран не гаснет.

**Правила**
- Фон `card-paper`, штрихи `card-ink` — в любой теме.
- Тихая зона вокруг штрихкода не меньше 10 модулей; ширина кода ≥ 75% экрана.
- Кнопка «Показать QR» и чип яркости — `card-chip`; вторичный текст — `card-ink-muted`.
- Открытие с «Дома» или виджета — один тап, без анимаций дольше 150 мс.
