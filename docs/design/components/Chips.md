# Chips

Фильтр-чипы (кто / тег / статус) и сегмент-контрол (виды одного экрана).

**Правила**
- Чип: пилюля 32 px, обводка `line`; выбранный — заливка `ink` с текстом `ground`. Число справа — моно.
- Чип человека выбирается его цветом: подложка `michael-soft`/`sofia-soft` и обводка цвета.
- Сегмент: дорожка `surface`, выбранный — `surface-raised` с обводкой `line`. Не больше трёх сегментов.
