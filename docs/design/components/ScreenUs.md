# ScreenUs

Экран «Мы»: числа пары, письмо-капсула, записки, капсулы, пульс дня — а ниже спокойным списком синхронизация, безопасность и лист восстановления.

**Правила**
- Числа — `number-xl` моно; «до годовщины» — цветом `link`.
- Капсула, которая ждёт вас, — карточка цвета автора с текстом `on-partner`.
- Настройки не прячутся в шестерёнку: это нижняя группа «Устройство и данные».
