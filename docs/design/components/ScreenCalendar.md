# ScreenCalendar

Экран «Календарь»: месяц сеткой с точками авторов, многодневные события полосой, ниже — «Ближайшие» списком.

**Правила**
- Точка/полоса = цвет автора (`michael`, `sofia`); общее событие — обе половинки.
- Сегодня — круг `flame` с цифрой `on-flame`; выбранный день — кольцо `ink-muted`.
- Числа и дни недели — моно; прошедшие/чужие дни месяца — `ink-faint`.
- Переключатель «Месяц / Неделя / Список» — `Chips` (сегмент) под заголовком.
- Мета события называет автора и последнюю правку с правильным родом: «добавила София», «изменил Михаил 2 мин назад».
