Вход и фейк-режим

  1. Монограмма — файл иконки, не набор шрифтом. Тот же знак висит в рамке на стене комнаты.
  2. Биометрия по умолчанию, PIN — запасной путь (4 цифры, моно-клавиши 76 px).
  3. Фейк-режим: тройное нажатие на монограмму (в рамке на стене) → приложение притворяется калькулятором. Калькулятор — системного вида, без цветов, шрифтов и знака МС.
